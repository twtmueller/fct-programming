# About the Task (16:35)

In this session, you will be rewriting a functionality implemented in
a procedural in a functional way. Along the lines, you will be exploring 
and applying concepts such as pure functions and currying to make your
codebase more composable and easier to reason about.

The functionality is based on the checkout process for a eCommerce cart,
where you have the items, need to find the prices and add them up. In a
final step, you will modify the way the displayed information is formatted.

As part of this session, I'm going to talk about:

1. Immutability
2. Pure functions
3. Currying

You will be actively coding for  most of the time, applying the concepts 
I'll introduce in a short demo-coding session.

Your tasks are described in the `INSTRUCTIONS.md` file.
